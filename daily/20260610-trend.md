tsconfig.jsonファイルの設定方法は、以下のようになっています。

1. **コンパイル対象のファイルを指定する**: `include`プロパティを使用して、コンパイル対象のファイルを指定します。たとえば、`include: ["src/**/*"]`と設定すると、srcディレクトリ以下のすべてのファイルがコンパイル対象になります。
2. **コンパイル結果の出力先を指定する**: `outDir`プロパティを使用して、コンパイル結果の出力先を指定します。たとえば、`outDir: "dist"`と設定すると、コンパイル結果はdistディレクトリに出力されます。
3. **コンパイルのオプションを指定する**: `compilerOptions`プロパティを使用して、コンパイルのオプションを指定します。たとえば、`target: "es5"`と設定すると、コンパイル結果はES5互換のコードになります。
4. **型チェックのオプションを指定する**: `compilerOptions`プロパティを使用して、型チェックのオプションを指定します。たとえば、`strict: true`と設定すると、厳格な型チェックが行われます。

tsconfig.jsonファイルの設定例は以下のようになっています。
```json
{
  "include": ["src/**/*"],
  "outDir": "dist",
  "compilerOptions": {
    "target": "es5",
    "strict": true
  }
}
```
この設定では、srcディレクトリ以下のすべてのファイルがコンパイル対象になり、コンパイル結果はdistディレクトリに出力されます。また、コンパイル結果はES5互換のコードになり、厳格な型チェックが行われます。
